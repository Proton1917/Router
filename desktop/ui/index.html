routerDESKTOP

连接你的第一个模型

选择客户端和服务商，Router 自动创建后台服务、模型配置与终端入口。

应用将统一更新后台程序、网页和适配脚本，并重启服务。API 凭据、模型配置和转写结果保留。

请先结束正在使用 Router 的客户端会话；转写任务完成或取消后即可更新。

接入服务

密钥保存到本机的受保护凭据文件。

平时使用主账号。官方客户端报告额度耗尽后，自动切换备用账号并恢复当前对话。登录和凭据由官方客户端管理。

创建后直接进入账号管理，逐个点击“官方登录”。切换会自动重启客户端，按原生会话恢复规则继续处理。

下载官方 .pkg 安装包并按系统提示完成安装，然后点击“刷新程序状态”继续。系统授权在 macOS 安装程序中完成。

启动命令

Router 会自动配置接口协议和认证方式。

命令名称会在新终端中作为 Router 入口生效；同名的系统程序可通过完整路径调用。

安装位置与高级设置

选中后向 ~/.zshrc 添加初始化语句，新终端即可使用命令。
